# lesson06-dp

《人工智能程序设计与实践》第 6 次课作业：贪心与动态规划。

## 文件

| 文件 | 内容 |
|---|---|
| `coin_change.py` | Step1 凑硬币：贪心 vs 动规（贪心 5 枚 / 动规 3 枚） |
| `knapsack.py` | Step2 0-1 背包（315、组合 [3,4,5]）、dp 最后一行、回溯路径、预算 800、必投约束 |
| `research_tasks.py` | 独立研究验证：8 皇后 92 解、完全背包对比 |
| `progress.md` | 课堂实践进度报告 |

## 运行

```bash
python coin_change.py
python knapsack.py
python research_tasks.py
```

环境：Python 3，仅标准库。背包采用“至多装满”。
